# Cadência

## Platform
web

## Stack
React e TypeScript propostos para o app estático; GitHub Pages + Supabase confirmados pelo usuário. Apple Design, Impeccable, Taste e React Bits solicitados.

## Users
João, 18 anos, quatro anos de treino; usa iPhone entre séries e computador para editar e acompanhar evolução.

## Product Purpose
Registrar cada série rapidamente, retomar sessões e ver os mesmos dados nos aparelhos, com privacidade.

## Operating Context
Academia, pausas curtas, uma mão e possível conexão instável. Ficha de quatro dias com sessão até 45 minutos.

## Capabilities and Constraints
Hoje, Agenda, Evolução, Meu treino; RIR opcional; calendário flexível; plano editável; cache e sincronização; acesso único autorizado; PWA no iPhone.

## Brand Commitments
Nome Cadência, símbolo C aprovado. Visual limpo, bonito, claro e de operação simples.

## Evidence on Hand
Proposta_site_treino.md aprovada e PDF Treino_repeticoes_e_revisao_dupla.pdf fora deste repositório. Não publicar dados pessoais.

## Product Principles
Uma série de cada vez. Salvar com status honesto. Poucos controles por tela. Histórico imutável ao editar plano. Sem assinatura paga não autorizada.
