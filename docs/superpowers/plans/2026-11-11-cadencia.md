# Cadência Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Entregar o diário de treino privado, instalável no iPhone e sincronizado entre dispositivos.
**Architecture:** React/TypeScript estático no GitHub Pages; IndexedDB como cache e fila; Supabase Auth, Postgres com RLS e Realtime. Documentos versionados por entidade permitem alterações idempotentes e conflitos explícitos.
**Tech Stack:** React, TypeScript, Vite, Supabase JS, IndexedDB, CSS e Motion. Componentes próprios com referência visual React Bits.
**Spec:** ../../../../Proposta_site_treino.md (aprovada; símbolo C, nome Cadência). A ficha de origem é Treino_repeticoes_e_revisao_dupla.pdf, fora do repositório.

## Global Constraints

- Português brasileiro, quatro áreas: Hoje, Agenda, Evolução, Meu treino.
- iPhone e computador; alvos de toque de pelo menos 44 px, teclado numérico e safe areas.
- RIR realizado opcional; carga e reps válidas para marcar uma série.
- Ficha inicial privada; nenhuma carga real, PDF pessoal ou credencial administrativa no repositório público.
- Dia previsto separado do realizado; alterações da ficha não reescrevem sessões.
- 56 séries planejadas; referências de supino pesado e moderado separadas.
- Sem backend pago nem hospedagem fora do GitHub Pages.
- Supabase criado e saudável em sa-east-1, custo confirmado pelo serviço em US$0/mês.
- GitHub de publicação: JoaoIfbaVamo; não usar joaovitorgoncalvesdev sem instrução do usuário.

## Review Focus

- Perda de conexão durante salvamento não duplica séries nem mostra sincronização falsa.
- Mudança concorrente na mesma entidade preserva versões; tombstone não é apagado por dispositivo antigo.
- Carga vazia/zero/menor que a barra e RIR vazio têm semânticas distintas.
- Fuso horário e data manual não confundem o treino de terça realizado na quarta.
- Edição de plano, limpeza e importação não destroem rascunho nem reescrevem histórico.

## Estrutura e interfaces

- src/domain.ts: tipos Entity, Plan, Session, SetLog, Activity, Profile; parsing, datas e aquecimento.
- src/storage.ts: cache IndexedDB por conta e fluxo de mudanças locais.
- src/sync.ts: envio RPC idempotente, recebimento incremental, conflitos e Realtime.
- src/auth.ts: cliente Supabase e configurações públicas.
- src/App.tsx: navegação e estados de autenticação.
- src/screens/: Today, Workout, Calendar, Progress, PlanEditor, Settings.
- src/components/: ícones, marca C, sheets, campos, temporizador e estados.
- src/styles.css: linguagem aprovada, acabamento Apple no iPhone e desktop.
- public/: manifesto, service worker, ícones e conteúdo público sem dados pessoais.
- supabase/: schema SQL revisável e instruções de implantação.
- tests/: testes de domínio, fila e merge; verificações de navegador.
- .github/workflows/pages.yml: build e deploy no Pages, com base na subpasta.
